# Veyra

Veyra is a modern visual creation platform inspired by the best ideas in collaborative design tools.

## Current milestone

The repository starts with a polished landing page and the first editor shell. The editor establishes the core interaction model: canvas, selection, tool rail, inspector, zoom and export controls.

## Product direction

- Visual design editor
- Projects and autosave
- Templates and assets
- Brand kits
- AI-assisted creation
- Collaboration
- Export pipeline
- Teams, billing and usage limits

## Stack

- Next.js App Router
- React + TypeScript
- Tailwind CSS
- Lucide icons

## Development

```bash
npm install
npm run dev
``

Open http://localhost:3000.
